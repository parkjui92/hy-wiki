# 내 자료로 만드는 LLM 위키 (`hy-wiki`)

2026-2 한양대학교 신흥기술영향평가세미나 · 10주차 실습 저장소

별도 프로그램이나 파이썬 설치 없이 **Claude Code 데스크톱 앱**에서 바로 열어 실습합니다.

---

## 폴더 구조 한눈에 보기

```text
hy-wiki/
├── CLAUDE.md                 ← AI가 따르는 위키 운영 규칙 5가지 (3막에서 함께 열어봄)
├── 1부_공통실습/             ← [1교시] 전원 똑같은 미니 자료로 생성·갱신·검증 완주
│   ├── 원자료/               ← 초기 공통 문서 3편 (.md)
│   ├── 추가자료/             ← 중간에 추가로 넣어 위키 갱신을 체험할 4번 문서 1편 (.md)
│   └── 위키/                 ← 1부 위키와 질문 답변이 만들어지는 곳
├── 2부_내위키/               ← [2교시] 각자 연구·업무·조 프로젝트 자료로 내 위키 만들기
│   ├── 내자료/               ← 본인 자료 2~3건을 넣는 폴더
│   ├── 예비자료/             ← 자료를 못 가져온 경우 선택해 쓸 수 있는 연구 AI 자료 3편
│   └── 위키/                 ← 나만의 위키와 질문 답변이 만들어지는 곳
└── 완성본_참고/              ← 실행이 막혔을 때 비교하거나 Claude 웹에 올려 쓸 예시 완성본
```

---

## 수업 중 복사해 쓸 지시문 4줄

### [1부] 공통 자료로 함께 익히기

1. **첫 위키 만들기**
   ```text
   1부_공통실습/원자료 문서들로 1부_공통실습/위키 에 위키 만들어줘
   ```
2. **새 자료 1편 추가해 기존 위키 갱신하기**
   ```text
   1부_공통실습/추가자료 의 새 문서를 1부_공통실습/위키 에 반영하고, 어느 페이지가 어떻게 바뀌었는지 알려줘
   ```
3. **영향 식별 질문 던지고 답변 저장하기**
   ```text
   1부_공통실습/위키 를 바탕으로, 공공·연구 현장에 AI를 도입할 때 누가 어떤 기대와 걱정을 겪는지, 또 자료끼리 엇갈리거나 아직 근거가 빈 곳은 어디인지 정리해줘
   ```

### [2부] 내 자료로 내 위키 만들기

4. **`2부_내위키/내자료/`에 내 문서 2~3건을 넣은 뒤 실행** *(예비자료 사용 시 `내자료` 대신 `예비자료` 입력)*
   ```text
   2부_내위키/내자료 문서들로 2부_내위키/위키 에 내 위키 만들어줘
   ```
   이후 본인이 실제로 궁금한 질문을 자유롭게 물어보세요. 답변은 `2부_내위키/위키/질문/`에 자동 저장됩니다.

## 내 자료 넣을 때 주의사항

- **권장 형식**: `.md`, `.txt`, 또는 텍스트 드래그가 되는 **10쪽 이내 짧은 `.pdf`** (긴 논문·보고서는 초록과 핵심 절만 복사해 `.md`나 `.txt`로 저장해 넣으면 가장 빠르고 정확합니다.)
- **피해야 할 파일**: 스캔된 이미지 PDF, HWP/HWPX, 30쪽이 넘는 대용량 파일, 타인의 개인정보·비공개 기밀 자료.
- **데이터 처리 안내**: 만들어진 위키 파일은 내 컴퓨터에만 남고 Git에 올라가지 않도록(`.gitignore`) 설정되어 있으나, 문서를 읽고 정리하는 AI 처리는 Claude 서버를 거칩니다.
