```text

├── 10주차_학생실습서.md
├── 1부_공통실습/
│   ├── 원자료/        ← 공통 자료(교수자가 작성한 수업용 요약본, 머리에 원문 주소)
│   ├── 추가자료/      ← 실습 2에서 반영할 새 자료. 반영 요청 전에는 읽지 않음
│   └── 위키/          ← 미리 채워 둔 시작 위키(목차 · 주제 페이지 · 변경기록)
│       └── 질문/03_메모초안.md  ← 실습 1에서 검토할 메모(정정 전 자료로 만든 출력)
├── 2부_내위키/        ← 수업 후 과제용(내자료 · 예비자료 → 위키)
└── 완성본_참고/
    ├── 공통_기본위키/  ← 시작 위키를 되돌릴 때 복사할 판(시작 상태와 같음)
    ├── 공통_갱신위키/  ← 새 자료 반영이 막혔을 때 복사할 판(추가자료 04까지 반영)
    ├── 공통_질문예시/  ← 04_메모수정 · 06_메모갱신 예시(읽기만)
    ├── 위키_그래프_시작.html  ← 시작 위키를 그래프로 보기(더블클릭 · 파일 이름을 누르면 내용 · 출처)
    └── 위키_그래프_갱신.html  ← 추가자료 04 반영 뒤 그래프(바뀐 페이지를 누르면 반영 전후 문장)
```

- `원자료/`는 발행기관의 원문이 아니라 수업용 요약본. 위키의 `[출처: …]` 링크 → 요약본 → 요약본 머리의 '원문' 주소 순서로 따라가 원문에서 확인

## 학생 실습 1 · 09:35–10:05 · 메모의 한 문장을 근거와 대조하고 고치기

**Step 6 · 지정 문장 대조**(요청문 없음)

- `1부_공통실습/위키/질문/03_메모초안.md`에서 96.9% 문장을 찾음
- 위키의 관련 페이지 → `원자료/03_현장설문과_연구윤리_사례.md` → 원문 주소 순서로 따라가며 **누가 · 무엇을 · 어떤 조건에서** 잰 수치인지 확인
- 판정: **유지 · 수정 · 판단 유보** 가운데 하나와 그 이유를 한 줄로 적음

**Step 7 · 수정 요청**: `[ ]` 두 곳을 내 판정과 이유로 바꿔 입력. 직접 고치고 싶으면 03을 복사해 `04_메모수정.md`로 저장한 뒤 직접 수정해도 됨

```text
1부_공통실습/위키/질문/03_메모초안.md의 96.9% 문장을 원자료와 대조한 내 판정은 [유지 / 수정 / 판단 유보]이고, 이유는 [이유]야. 이 판정대로 메모를 고쳐줘. 유지면 그 문장을 그대로 두고, 판단 유보면 문장 끝에 확인이 필요하다는 단서만 붙여줘. 원자료보다 넓게 쓴 표현이나 빠진 조건이 더 보이면 함께 알려줘. 본문은 1,200자를 넘기지 말고, 본문 아래에 검증 기록(확인한 자료와 위치, 판정과 이유, 수정 전후 문장, 이 수정으로 달라지는 결론)을 따로 적어서, 초안은 그대로 두고 1부_공통실습/위키/질문/04_메모수정.md에 저장해줘.
```

**Step 7-2 · 위키 바로잡기**(조건부): 위키에도 같은 문제가 있을 때만 해당 문장을 고침. 고칠 곳이 없다는 답도 결과

```text
1부_공통실습/위키/질문/04_메모수정.md의 검증 기록에서 고친 문제와 같은 문제가 1부_공통실습/위키 주제 페이지에도 있는지 확인해줘. 있으면 해당 문장만 고치고 위키 전체를 다시 만들지는 마. 고친 페이지와 고치기 전후 문장, 근거가 된 원자료 위치를 변경기록.md에 남기고, 원자료와 질문 폴더 파일은 수정하지 마. 고칠 곳이 없으면 고치지 말고 이유를 알려줘.
```

- 제출: `04_메모수정.md`(본문 + 아래 검증 기록). 본문 분량은 제목과 아래 절을 빼고 공백을 포함해 셈
- 완료 기준: 근거 위치와 확인 범위를 대고 유지 · 수정 · 판단 유보의 이유를 설명할 수 있음. 오류 수나 고친 글자 수로 판단하지 않음

## 수업 후 과제 · 내 위키 만들기

## 내 자료를 넣을 때

- 권장 형식: `.md`, `.txt`, 글자가 선택되는 10쪽 안팎 PDF. 긴 문서는 관련 부분만 발췌해 `.md`로 저장하고 제목 · 저자 · 연도 · 쪽을 함께 적음
- HWP · 스캔 PDF는 변환 시간이 들어 오늘 실습에서는 피함. 필요한 절만 복사해 `.md`로
- 다른 사람의 개인정보 · 공개할 수 없는 자료는 넣지 않음. 파일은 내 컴퓨터에 남지만 읽고 정리하는 처리는 Claude 서버를 거침

## 실행이 어려울 때

|---|---|---|
| `완성본_참고/공통_기본위키/` | 시작 위키와 검토용 메모(받았을 때와 같은 상태) | 시작 위키가 망가져 되돌릴 때 |
| `완성본_참고/공통_갱신위키/` | 실습 1 · 2를 거쳐 추가자료 04까지 반영한 위키 | 실습 2의 새 자료 반영이 막혔을 때 |
| `완성본_참고/공통_질문예시/` | `04_메모수정` · `06_메모갱신` 예시 | 복사하지 않고 읽기만 |

- 내 위키에 이미 생긴 파일은 지우지 않고 `위키_보관` 폴더로 옮긴 뒤 복사(이름이 다른 옛 페이지가 섞이지 않게). `질문/` 폴더의 내 파일은 그대로 둠
- 예시는 빈 사본에서 수업 요청문을 실행해 만든 것. 페이지 이름 · 문장은 내 결과와 다를 수 있고, 같아야 정상인 것이 아님
- 위키 페이지 · 질문 예시의 링크는 `1부_공통실습/위키/` 안의 위치를 기준으로 걸려 있어 `완성본_참고/` 안에서는 열리지 않음. 읽을 때는 `1부_공통실습/원자료/`나 같은 판의 위키 폴더에서 같은 이름 파일을 직접 열기

### 방법 1 · 직접 복사(사용량 제한 · 로그인 문제로 AI를 쓸 수 없을 때도 가능)

1. Finder(맥) · 파일 탐색기(윈도)에서 `hy-wiki/1부_공통실습/` 안에 새 폴더 `위키_보관`을 만듦
2. `1부_공통실습/위키/` 안의 파일 가운데 `질문` 폴더를 뺀 나머지(목차 · 주제 페이지 · 변경기록)를 `위키_보관/`으로 옮김
3. `완성본_참고/공통_기본위키/`(새 자료 반영이 막혔으면 `공통_갱신위키/`) 안의 파일 가운데 `질문` 폴더를 뺀 나머지를 복사(맥 Cmd+C · 윈도 Ctrl+C) → `1부_공통실습/위키/`에 붙여 넣기(맥 Cmd+V · 윈도 Ctrl+V)
4. 검토용 메모(`질문/03_메모초안.md`)가 없어졌으면 `공통_기본위키/질문/03_메모초안.md`만 내 `질문/` 폴더로 복사
5. AI를 계속 쓸 수 없으면 복사한 목차와 주제 페이지를 직접 읽고 원자료와 대조. 메모는 03을 복사해 `04_메모수정.md`로 저장한 뒤 직접 고침

### 방법 2 · Claude Code에 복사 요청
