# 업무 활용 메모 (초안): AI를 처음 쓰는 동료에게

> 정정 전 자료로 만든 검토용 출력. 원자료를 원문과 대조해 고치기 전(2026-11-06) 판으로 AI가 쓴 메모를 그대로 둠. `[위키: …]`에 적힌 페이지 이름은 지금 위키의 페이지 이름과 다를 수 있음

※ 근거는 1부_공통실습 위키에 있는 자료만 썼습니다. 대상 기술이 근거마다 달라 괄호에 적었습니다.

## 1. 어디에 도움이 될 수 있나

- 데이터 입력·고객 응대 같은 정형·반복 업무, 대량 자료 요약에 도움이 될 수 있다는 평가가 있습니다(AI 에이전트·생성형 AI) [위키: 업무생산성_기대와_한계.md / 출처: 02_해외_감사원보고서_요약.md].
- 국내 공무원들이 가장 기대한 활용은 문서 요약·회의록 작성, 법령·지침·판례 자료 검색과 대조였습니다(생성형 AI, 기대를 물은 설문이며 실제 효과 아님) [위키: 업무생산성_기대와_한계.md / 출처: 03_현장설문과_연구윤리_사례.md].
- 적용 조건: 공공 업무에서 업무 시간이나 품질이 실제로 얼마나 나아지는지 잰 수치는 아직 없습니다 [위키: 업무생산성_기대와_한계.md].

## 2. 쓸 때 꼭 지킬 것

- **결과물은 반드시 직접 확인하세요.** 국내 공무원 96.9%가 AI 결과물은 반드시 검토가 필요하다고 답했습니다(생성형 AI, 인식 조사) [위키: 업무생산성_기대와_한계.md / 출처: 03_현장설문과_연구윤리_사례.md].
- **참고문헌·인용은 원문을 열어 확인하세요.** 해외 정부 발주 보고서에서 AI가 만든 실재하지 않는 참고문헌이 발견되어 대금 일부를 환불한 사례가 있습니다(생성형 AI, 보도 기반) [위키: 정책연구_허위인용과_연구윤리.md / 출처: 03_현장설문과_연구윤리_사례.md].
- **같은 질문에도 답이 달라질 수 있습니다.** 해외 한 시의 안내 챗봇이 같은 질문에 다른 답을 내고 공식 안내와 반대로 잘못 안내한 사례가 있습니다(생성형 AI 챗봇) [위키: 오류책임과_행정신뢰.md / 출처: 02_해외_감사원보고서_요약.md].
- **개인정보·내부 자료는 넣기 전에 확인하세요.** 개인정보나 내부 시스템 접근 권한을 받은 에이전트는 해킹 표적이 될 수 있습니다(AI 에이전트) [위키: 오류책임과_행정신뢰.md / 출처: 02_해외_감사원보고서_요약.md]. 국내 공무원의 우려 2순위도 보안·개인정보 유출이었습니다 [위키: 오류책임과_행정신뢰.md / 출처: 03_현장설문과_연구윤리_사례.md].
- **결과의 책임은 쓴 사람에게 있습니다.** 국가R&D AI 연구윤리 가이드는 AI를 도구로 한정하고 최종 결과물의 책임을 연구자에게 두며, 사용한 모델과 버전을 밝히도록 합니다(국가R&D 연구 대상, 보도 기반) [위키: 정책연구_허위인용과_연구윤리.md / 출처: 03_현장설문과_연구윤리_사례.md].

## 3. 기대를 낮춰 둘 것

- AI 에이전트는 아직 좁은 용도에 한정되고 성능이 제한적입니다. 최고 성능 에이전트도 소프트웨어 개발 과업의 약 30%만 자율적으로 끝냈습니다(소프트웨어 개발에서 잰 값, 공공 업무 아님) [위키: 업무생산성_기대와_한계.md / 출처: 02_해외_감사원보고서_요약.md].
- 국내 공공 부문의 AI 에이전트 활용은 초기·시범 단계입니다 [위키: 공공부문_도입단계와_시민참여.md / 출처: 03_현장설문과_연구윤리_사례.md].
- 너무 의존하면 스스로 판단하는 능력이 약해질 수 있다는 우려가 있습니다 [위키: 고용과_숙련도_논쟁.md / 출처: 01_국내_기술영향평가_요약.md, 02_해외_감사원보고서_요약.md].

## 4. 아직 확인되지 않은 것

- 우리 업무에서 AI로 실제 시간이 얼마나 줄어드는지, 검토 시간이 그 효과를 얼마나 상쇄하는지.
- 행정 분야에서 AI 오류가 났을 때 책임을 누구에게 두는지 정한 제도.
- 한국어로 썼을 때 성능이 영어보다 얼마나 떨어지는지.
